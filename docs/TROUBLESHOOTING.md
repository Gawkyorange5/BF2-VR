# Troubleshooting v1.1.0

See [installation and troubleshooting](INSTALL.md#troubleshooting-and-reports)
for the supported renderer check, optional Alt-Tab hotfix link, Steam, DZB2
Medium Lighting, resolution choices, logs and rollback instructions.

The hotfix is conditional. A compatible installation does not need it. An
unknown renderer is not automatically approved merely because it says 1.5.

For known limits, see [release notes](../RELEASE-NOTES.md#known-limits-and-future-work).
For corrected issues, see [the bug-fix list](FIXES.md).
